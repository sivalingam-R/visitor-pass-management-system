# Visitor Pass Management System (VPMS)

## Project Overview

The Visitor Pass Management System (VPMS) is a full-stack web application that helps organizations manage visitors efficiently through role-based access control.

The system supports three user roles:

- Administrator
- Receptionist
- Employee

---

## Tech Stack

### Frontend

- React
- Vite
- React Router
- Axios
- CSS

### Backend

- Node.js
- Express.js
- JWT Authentication

### Database

- MongoDB Atlas

---

## Features

### Authentication

- User registration
- User login
- JWT authentication
- Role-based authorization

### Visitor Management

- Register visitors
- Approve visitors
- Reject visitors
- Check-in visitors
- Check-out visitors

### Dashboard

- Total employees
- Total visitors
- Pending visitors
- Checked-in visitors
- Today's visitors

### Reports

- Activity logs
- Visitor reports
